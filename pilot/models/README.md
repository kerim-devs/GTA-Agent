The default detector is the Apache-2.0 YOLOX-L ONNX export from the official Megvii 0.1.1rc0 release, using 640-pixel BGR letterboxing and confidence 0.4. Run `.venv/bin/python tools/fetch_models.py` from `pilot` before starting it. Its SHA-256 is `7860ae79de6c89a3c1eb72ae9a2756c0ccfbe04b7791bb5880afabd97855a411`. The approximately 216 MB weights are ignored by git and checked before loading. Inference never downloads anything.

Inference uses ONNX Runtime 1.31.1 with CoreML MLProgram and `MLComputeUnits=ALL`; CPU is available only for unsupported partitions. CoreML must be available and its macOS cache writable. The existing `LICENSE.yolox` covers the weights. ONNX Runtime is MIT-licensed.

The fetch tool also accepts `--model yolox_tiny.onnx`, `yolox_s.onnx`, `yolox_m.onnx`, or `rtdetr_v2_r18vd.onnx` for repeating the comparison. Every download has a pinned digest. RT-DETR-v2 R18VD is the Apache-2.0 [ONNX Community export](https://huggingface.co/onnx-community/rtdetr_v2_r18vd-ONNX); its hash is `583a236ac21c95a7fd94f284fc21485e42355bfef82c27011ba78fbc09ee87e2`. It is an experimental comparator, not the default. Native YOLOX tiles are generated locally from verified official exports by `lab/objects/compare.py`, with the packages of the `compare` dependency group (`uv sync --group compare`), which the default environment leaves out.

The selection and limitations are documented in `docs/reports/P14b-objects-that-are-found.md`. Faster inference does not establish the required detection accuracy; this model remains below the acceptance targets.

The heavier torchvision FasterRCNN ResNet50 FPN v2 comparison uses the official PyTorch checkpoint, SHA-256 `dd69338a24b8d7381807e247652bdc356325bcbaf1cd3e092e00e0a1a58706bf`. Fetch it with `--model fasterrcnn_resnet50_fpn_v2_coco-dd69338a.pth` and run `PYTORCH_ENABLE_MPS_FALLBACK=1 .venv/bin/python ../lab/objects/compare_torchvision.py` from `pilot`, also with the `compare` group installed. The model runs on MPS; unsupported individual operators may fall back to the CPU. It is not the selected backend.
