Run the tool from the repository root with the Pilot environment. PyAV 19.0.2 is the version used for the recorded checks.

`pilot/tools/trim.py plan RECORDING --derived DERIVED_FOLDER --out PLAN.json` writes an editable list of cut and keep decisions. Only human controller state is considered. Missing human events produce an explicit no-cut plan. Subtitle, objective, dialogue and banner text retain five seconds of context; only uninterrupted, unprotected rest of at least sixty seconds is eligible, with another five seconds retained at either end of the eligible stretch. Missing section coverage is retained. A single recorded neutral human state counts as human input, and an otherwise fully idle recording is flagged before cutting.

`pilot/tools/trim.py cut RECORDING --plan PLAN.json --out NEW_FOLDER` copies complete interior GOPs with PyAV. Both boundaries must be keyframes inside the planned interval. The final GOP and groups whose presentation frames straddle the next keyframe are retained. A plan can therefore remove less than requested, including nothing. The source is never changed and an existing output folder is refused. An interrupted output is not verified and must not replace a source.

`pilot/tools/trim.py check SOURCE NEW_FOLDER` decodes both videos to the end, checks every frame row, compares at least fifty pictures by original frame_id plus pictures at splices, verifies the exact retained controller lines, and checks metadata counts and playback durations. It exits unsuccessfully on a mismatch. Recordings with fewer than fifty kept frames cannot meet this verification contract.

`i` is the position in the current video, while `t` and `frame_id` remain original. Top-level `meta.json.seconds` retains the original recording-clock duration. Playback durations and actual cuts are under `meta.json.trim`. Reader continuity stops at frame-clock gaps over one second; a missing controller state after a cut stays unknown until another retained event establishes it. Derived data must be rebuilt, including no-cut remuxes for consistency. Do not copy source derived data into a trimmed recording's output directory.

`env -u PS5_HOST pilot/.venv/bin/python lab/trim/evaluate.py` reproduces the three reference plan/cut/check results, processing one copied recording at a time. It refuses a nonempty work directory and preflights two copies against a 2 GB limit. It retains the last trimmed copy for `env -u PS5_HOST zsh lab/process-recordings.sh "$PWD/lab/trim/work/trimmed" http://127.0.0.1:1=qwen/qwen3-vl-8b`. The deliberately unavailable judge selects the local-reader fallback. Native Vision may require execution outside the sandbox. Remove the generated contents of `work/` after collecting the results; `work/` is ignored. The P49 report records the completed run and its limitations.
