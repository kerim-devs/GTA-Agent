P17 visual evidence uses 72 frozen vehicle-map crops from recording `20261110-093238`, sampled with seed 17. Each tile shows the original RGB HUD enlarged twice, its recording time and frame-cache key, and the inferred path in red. NONE means the reader abstained. The visual audit covers every tile; labels and path fingerprints are in [labels.json](labels.json), with source frame indices in [selection.json](selection.json).

From `pilot/`, regenerate the images and score the frozen labels with `.venv/bin/python tools/evaluate_roam.py --out ../lab/roam --check`. It intentionally exits 1 while the targets are missed. An absent labels file is reported as unlabelled, and changed path hashes reject stale visual labels. The initial sampling command was `.venv/bin/python tools/evaluate_roam.py --select ../lab/minimap/data --out ../lab/roam --seed 17 --count 72`; selection is frozen and cannot be overwritten accidentally. Recompute the wider recording pace sample with `--pace-data ../lab/minimap/data`. Run the rendered road-network simulation with `.venv/bin/python tools/sim_roam.py --seeds 20 --seconds 45 --out ../lab/roam/simulation-results.json`. These commands are offline and do not contact a console.
