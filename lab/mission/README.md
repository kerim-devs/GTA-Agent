This is an offline evidence corpus for P30. No script invokes a model, daemon, controller or PS5 host. Run the scripts with the interpreter from `pilot/.venv` and working directory `pilot`.

`../lab/mission/build_cases.py` copies 18 unchanged requests and recorded model answers from the two pilot sessions named in each source record. `../lab/mission/read_frames.py` reconstructs 142 requests from the Wi-Fi recording using the package minimap and HUD readers and the latest preceding cached OCR observation. `../lab/mission/read_extra_frames.py` reconstructs four frames with manually labelled non-player vehicles and nine frames from Kerim's recording. The manual objects are explicitly labelled evidence, not detector predictions; no confidence score is invented. Kerim's samples have no OCR or object observations.

The frame-derived requests have no invented events, skill history or notebook. Each starts a fresh minimap pipeline, so motion/GPS history is not reconstructed. Video is indexed through the recording's frame table, not by assuming a fixed capture rate. The JSON files retain source paths, frame indices, times and label references; the tests use these frozen JSON files and need neither the original videos nor model weights.

`../lab/mission/compare.py` evaluates all 173 cases using an injected local fallback stub. It writes `comparison.json` with full plans, provenance, decision counts, timing and a judgment for every case, plus the human-readable table in `cases.md`. A delegated case has no rule plan and is never represented as a new model answer. The only actual model answers are the 18 copied from the saved sessions.

The test suite distinguishes unchanged recorded requests from explicitly counterfactual safety probes for failed calls, reflex events, wanted-state permutations and the future movement-judge seam. Those probes are not added to the recorded-case statistics. The corpus contains no saved failed-skill request, explicit German combat imperative or mission-letter instruction. The recorded fight/model experiments summarized in `docs/LOG.md:64` have no corresponding raw model response available here. These gaps must not be presented as verified combat or mission-letter coverage.
