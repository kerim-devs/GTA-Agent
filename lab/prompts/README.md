These are local, read-only recording observations for P71. The controller was never contacted. `evidence.json` contains the corrected correlations and the limits of the measurements; `p71-fixture-raw.json` preserves the original OCR spellings. `p71-menu-readings.json` preserves shop text and boxes. Contact sheets show the three observed shop types, and the glyph sheet records an insufficient six-sample experiment. No glyph classifier is enabled.

From the repository root, `pilot/.venv/bin/python lab/prompts/replay.py` extracts the eleven prompt frames from the original recordings using their recorded frame indices. `PYTHONPATH=pilot/src pilot/.venv/bin/python lab/prompts/measure.py` prints the training and independent prompt scores. The portable replay tests in `pilot/tests/test_prompts.py` and `pilot/tests/test_place.py` use these saved frames with frozen OCR and scripted reactions. Their transitions do not establish that a real purchase succeeded. The report distinguishes those tests from independent recognition and a live console run.
