P11 implements `pilot overlay`, a read-only OBS browser overlay bound exclusively to `127.0.0.1`. The default port is 9396 and the recordings root is the conductor's `~/recordings/pilot`; `--root` and `--port` override those values. The server serves bundled HTML, CSS and JavaScript, a complete JSON snapshot at `/api/state`, and server-sent snapshots every 200 ms at `/events`. EventSource reconnects automatically and receives the complete current state. The implementation adds no dependency, does not construct the driving pipeline or bridge, and does not contact the live daemon, hardware, credentials or an external service.

The live reader selects the newest immediate session directory containing `head.jsonl` or `play.jsonl`, using directory modification time and name as a tie-breaker. It resets displayed state on a session change. It reads complete newline-terminated records, retains partial lines, ignores malformed records, bounds partial-line memory, and detects inode replacement, truncation and rewrites near its read position. Missing files and missing roots are normal waiting states. After three seconds without a valid new record, the last display remains visible with “Keine neuen Daten”; the logs contain no definitive live-session end marker, so inactivity is not presented as a confirmed end.

The prominent sentence and multi-step plan come from the most recent `head.jsonl` response with `applied=true` and without `overtaken=true`, using `sentence` and `plan[].name`. A new request sets “Denkt nach”; its matching response clears it. A stale connection or ended recording hides that indicator. The objective and help panels use the latest request's `request.objective` and `request.help`, and disappear when absent. The activity panel uses `play.jsonl.skill.name` and `skill.status`; known skills have German labels, while unknown identifiers appear as “Aktion”. The plan represents the last accepted plan because the log does not expose the runner's remaining queue. Speed comes from `reading.gps_speed` multiplied by 3.6, and remaining distance from `reading.gps_distance`, with metres or kilometres selected for display. Missing or invalid readings show no invented number. A `status=409` records a controller intervention; the indication persists until `sent=true` with `status=200` proves a subsequent accepted send, or a new session starts.

P10 does not persist shadow mode. The decision for this card is an explicit `--shadow` display flag for a session the operator knows was run in shadow mode; absence of pad sends is not treated as evidence. The flag only labels the overlay and never changes game execution. An explicit boolean `shadow` in a play record, if supplied, takes precedence. The operator must set or remove the flag appropriately when changing run mode.

`pilot overlay --demo /absolute/path/to/session` replays a finished recording once at recorded pace and leaves the final display visible with “Aufzeichnung beendet”. Play timestamps are session-relative, while head timestamps use monotonic observation time. The current conductor creates its startup head request on the first fresh play tick, so the demo aligns that pair and preserves all subsequent timestamp differences. Response timestamps already identify the tick that applied the answer; duration is not added again. If an incomplete recording lacks that pair, head events are aligned to the first request at zero as a best-effort fallback. Synchronization of incomplete or manually edited historical logs cannot be guaranteed. Reopening the page reconnects to the current replay position; restart the command to replay from the beginning.

For OBS, start `.venv/bin/pilot overlay` from `pilot`, or use `.venv/bin/pilot overlay --demo /absolute/path/to/session` for an offline rehearsal. Add a Browser source on the same computer with URL `http://127.0.0.1:9396/`, width 1920 and height 1080, and place it above the game capture. Keep the page background transparent and enable source refresh when the scene becomes active if desired. A changed port must also be changed in the Browser source URL. Refreshing or hiding the source does not send game commands. All displayed labels are German; system fonts and local package assets require no CDN, font service or internet access.

The editable appearance is concentrated at the top of `pilot/src/pilot/overlay_web/overlay.css`. `--panel-bg`, `--text-color`, `--muted-color`, `--accent-color` and `--border-color` control colours and transparency. `--font-family`, `--body-size`, `--sentence-size`, `--skill-size`, `--label-size` and `--speed-size` control typography. `--panel-radius` and `--panel-padding` control panel shape. The `--decision-*`, `--activity-*`, `--context-*` and `--telemetry-*` groups control each panel's position and dimensions. The default places the sentence along the lower centre, activity at the upper right, context at the upper left and telemetry at the lower right. Text is inserted through `textContent`, shortened before rendering and constrained by line clamps or ellipsis inside bounded panels.
