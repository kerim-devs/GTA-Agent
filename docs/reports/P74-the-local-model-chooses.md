P74 implements an optional local vision chooser, a MissionHead-compatible LocalHead, and an isolated errands adapter. Only the card-owned modules, their tests, lab/chooser, and this report changed. The head owns no goal. It builds registry-validated plans from the current observations, sends one small image with a fixed question and at most two explicitly observed objective/help lines, and uses the first safe candidate when no confident answer arrives. Invalid letters, missing scores, low scores, refusal, timeout, and missing configuration all abstain. The starting threshold is 0.5 and remains unmeasured on the real model. Completed probabilities are included in the reason, including scores rejected by the threshold.

The client permits one in-flight request and has no backlog. Its wait includes image preparation and network time and reserves up to 50 ms for returning before the caller deadline. LocalHead caps its entire requested decision budget at 1.5 seconds. Failed skills are removed from the next menu using actual nested skill_failed events and last_skill; failures do not permanently ban a choice. Unknown wanted state and active stars both exclude set_waypoint. Stuck screens offer single button presses with Circle first, using footer observations where available. Visible routes must be yellow or purple; the string none is not treated as a route. Vehicle detections use the real kind field, and drive_route completion supplies arrival evidence. Health loss is detected between successive HUD observations because the existing event stream has no ordinary health-delta event.

ErrandChooser is a callable taking candidates with name, description, and weight fields, either dictionaries or objects, and returns the original candidate or None. Weights and input objects are preserved so Goals can retain its seeded fallback. Call observe(request) before selection. Model choices are recorded automatically; call record(candidate) only after a seeded fallback to keep the rolling three-choice history complete. A candidate chosen twice in those three is omitted from the model menu.
